# danielwork｜Three.js 精緻 3D 微縮工作群島 V6

基於 V5 **原始程式直接修改**，不是另寫一套流程；`data/links.js` 保持原樣。視覺定位改為 **精緻 3D 微縮景觀**，不再刻意強調 Low-poly 的大型三角形色塊與方塊切面。

## V6 實際改動

| 項目 | V5 | V6 |
|---|---|---|
| 主題島邊緣細分 | 192 | 320 |
| 島嶼地表徑向細分 | 20 | 56 |
| 岩壁垂直細分 | 12 | 24 |
| 動態海面網格 | 192 × 192 | 桌機 384 × 384／手機 256 × 256 |
| 水面外觀 | 平滑主波紋 | 保留 GPU 主波浪，增加細波紋反光 |
| 建築外殼與基座 | 尖銳立方體邊 | 圓角幾何（RoundedBoxGeometry）與細分窗框 |
| 小島步道 | 長方形通道 | 一連串圓角鵝卵石步道 |
| 樹冠／雲 | 多面體／錐體 | 柔和球冠、層疊樹冠及平滑立體雲 |
| 海岸 | 岩壁與零星石塊 | 平滑細石與連續弧形水線泡沫 |
| 景觀 | 樹木、花草 | 保留並新增公園長椅及小路燈 |
| 巡航船 | 縮放的幾何圓柱 | 曲線船首船殼＋圓角船艙 |

**設計邊界：** 中央主島是 `DANIEL WORK / 我的工作島` 招牌；六座工作島維持原分類、原互動。建築最大寬仍約為島嶼寬度 1/3（保留 V4 比例設定 `BUILDING_SCALE = 0.66`）。場景不含教堂、十字架及宗教圖騰，原有分類文字不作改動。

## 功能保留

- 六大分類、共 43 個第一層超連結；分類面板、建築點擊、全站搜尋、快速導航。
- 海浪、巡航船、魚群、移動雲朵、拍翅海鳥。
- 手機單指平移（可切換旋轉）、雙指平移縮放；桌機左鍵旋轉、右鍵平移。
- 可直接放到 GitHub Pages `danielwork` 儲存庫的根目錄。

## 上傳 GitHub Pages

ZIP 根目錄內：`index.html`、`css/style.css`、`data/links.js`、`README.md`、`.nojekyll`。上傳後，在 GitHub 專案的 **Settings → Pages → Deploy from a branch → main → /(root)** 啟用。Three.js 固定使用 `0.187.0` CDN，網頁開啟需網路；不需要 Node.js、資料庫或 API。

本版修改：`index.html`、`README.md`；保留 V5 的 `css/style.css`、`data/links.js`、`.nojekyll`。已完成程式語法、ZIP 結構、資料筆數檢查。實際 WebGL/不同手機機型效能仍需實機確認，不能保證所有設備同樣流暢。ZIP 中未包含第三方 CDN 原始碼。
